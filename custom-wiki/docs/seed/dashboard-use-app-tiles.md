# Use Apps Dashboard tiles

**App:** Apps Dashboard  
**Audience:** ops / admin  
**Last verified:** 2026-08-07

## Goal
Open stack applications from the dashboard and read Online/Offline health.

## Prerequisites
- Staff Authelia access
- URL: https://dash.kecktech.net (alias: https://dashboard.kecktech.net)

## Steps
1. Open https://dash.kecktech.net
2. Sign in via Authelia
3. Review tile status badges (Online / Offline)
4. Click a tile to open the app in a new tab

## Verify
Most tiles show Online; Authelia-protected apps may show Online with SSO challenge.
