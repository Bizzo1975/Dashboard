# Create your Vaultwarden vault

**App:** Vaultwarden  
**Audience:** end-user  
**Last verified:** 2026-08-07

## Goal
Create or unlock your password vault in the Kecktech Vaultwarden instance.

## Prerequisites
- Invitation or account from Kecktech
- URL: https://vault.kecktech.net

## Steps
1. Open https://vault.kecktech.net
2. Complete Authelia if prompted
3. Create an account or log in with your master password
4. Install a browser extension if you will autofill

## Verify
You can create a test login item and see it in the vault list.
