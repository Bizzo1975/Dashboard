# Open a support ticket in Zammad

**App:** Zammad  
**Audience:** end-user  
**Last verified:** 2026-08-07

## Goal
Create a new help-desk ticket so Kecktech can track and respond.

## Prerequisites
- Customer or staff account
- URL: https://support.kecktech.net (alias: https://tickets.kecktech.net)

## Steps
1. Open https://support.kecktech.net
2. Authenticate via Authelia if prompted
3. Choose **New ticket** (or equivalent)
4. Set subject, group/category, and description
5. Submit and note the ticket number

## Verify
The ticket appears in your ticket list with status New/Open.

## Related
- Customer reply to a ticket
- Portal sign-in
